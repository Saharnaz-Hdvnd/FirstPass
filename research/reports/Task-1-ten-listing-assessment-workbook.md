# Task 1: ten-listing manual assessment workbook

Purpose: develop the rubric and annotation manual, not estimate fraud prevalence. No real listings have been assessed in this workbook.

States: supported / contradicted / unknown. Blank means not yet assessed and must not be counted as a completed annotation. Keep unknown separate from not applicable.

Use Pass 1 for the listing-only snapshot and Pass 2 for additional verification. Duplicate each rule table for a separate reviewer or pass. Never overwrite the earlier assessment.
