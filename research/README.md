# Research archive

These files preserve earlier rubric versions, the ten-listing pilot, official VIN-decoder records and paper notes. Earlier reports use earlier formulas; **the current software excludes unknown checks from the score**. Historical totals have not been retroactively recalculated or validated.

The current implementation is described in the repository README and README.txt. Two human reviewers and broader validation are still needed. Public listing/source URLs and findings are retained in the pilot JSON and reports. Bulk third-party photo copies and raw browser captures are not republished. The original PowerPoint was unavailable at its supplied temporary path when this repository was assembled.
